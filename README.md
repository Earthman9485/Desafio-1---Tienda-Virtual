# Desafio 1 - Tienda Virtual
## Nombre: Matías Jeronimo Vallejo Patiño
## Grado: 1008


Descripción:
Este proyecto es una Tienda Virtual en consola programada en Python. Se aplica programación orientada a objetos (POO), usando herencia para los tipos de usuarios y encapsulamiento para proteger datos sensibles como los precios y el inventario de los productos.

Historias de Usuario del Proyecto:
1. Como cliente, quiero ver el catálogo de productos para elegir qué comprar.
2. Como cliente, quiero agregar productos a un carrito para comprar varios artículos.
3. Como cliente, quiero ver el total de mi compra para saber cuánto pagar.
4. Como administrador, quiero agregar nuevos productos para actualizar el inventario.
